# 技术路线

本项目拟搭建一个面向心理测量服务的网页平台，用于开展多模态情绪感知能力测评。系统整体按照“题库建设—测评交互—智能推题—自动评分—数据分析—报告生成”的流程设计，形成从题目呈现、用户作答、数据采集到结果反馈的完整测评闭环。

平台主要包括六个核心模块。

第一，题库管理模块，支持测评设计者上传图像、文本、视频等多模态情绪素材，并为每道题设置主导情绪标签、情绪强度标准值、题目模态和难度等信息。题库建设过程中，需要统一情绪标签体系，建立标准答案，并控制不同模态、情绪类别和难度水平的题目比例，以保证测评结果的可靠性。

第二，测评交互模块，负责在网页端展示题目并收集用户作答。系统会根据题目类型自动呈现图片、文本对话或视频内容，用户需要选择最符合情境的情绪标签，并对情绪强度进行评分。若题目涉及多个人物，则分别设置独立作答区域。同时，系统记录作答时长、停留时间、修改答案、跳题或返回等行为数据，为后续分析提供辅助依据。

第三，智能推题模块。系统初期可采用固定题量和固定比例的题目抽取方式，保证不同用户测评内容相对一致。后期可根据用户实时表现引入自适应推题机制。当用户在某一模态或情绪类别上的表现波动较大时，系统可适当增加相关题目；当用户连续答对或答错时，系统可动态调整题目难度，从而提高测评效率和结果稳定性。

第四，自动评分模块。用户完成作答后，系统在后台依据标准答案进行实时评分。评分由情绪标签得分和情绪强度得分组成，其中标签部分根据选择是否正确计分，强度部分根据用户评分与标准强度值之间的距离进行计算。

第五，数据分析模块。测评结束后，系统汇总用户全部作答结果，生成总体得分、图像/文本/视频分项得分、不同情绪类别得分、情绪标签识别能力、情绪强度判断能力和反应时间等指标，并通过雷达图、柱状图、饼图等方式形成能力画像。

第六，报告生成模块。系统将结构化测评结果通过 API 输入大语言模型，生成个性化文字报告。报告不由大模型直接判分，而是基于已计算出的量化结果进行解释，内容包括总体表现、优势与不足、分项分析和提升建议。由此，平台既能保证心理测量过程的标准化和可解释性，也能提升测评反馈的智能化与易读性。
